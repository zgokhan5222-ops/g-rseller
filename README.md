# ROTA Psikoteknik — Tek klasör GitHub/Vercel paketi

Bu pakette klasör yoktur. HTML, CSS, logo, fotoğraflar ve video aynı ana dizindedir.

## GitHub'a yükleme
1. ZIP dosyasını bilgisayarında çıkart.
2. Klasörün içindeki tüm dosyaları Ctrl+A ile seç.
3. GitHub deposunda Add file > Upload files bölümüne sürükle.
4. Commit changes ile kaydet.

GitHub ana ekranında `index.html`, `rota-logo.jpg`, `merkez-bekleme-alani.jpg`, `style.css` ve diğer dosyalar yan yana görünmelidir.

ZIP dosyasının kendisini yükleme; ZIP'in içindeki dosyaları yükle.

## Vercel
- Framework Preset: Other
- Root Directory: ./
- Build Command: boş
- Output Directory: .
- Install Command: boş

Eski `public` veya `assets` klasörleri depoda kalmışsa sil. Sonra Vercel'de cache kullanmadan Redeploy yap.
